## Section 10: Setup Checklist

### Where to install these templates:

**WhatsApp Business**
1. Open WhatsApp Business app
2. Settings → Business tools → Quick replies
3. Add a shortcut for each (e.g., `/welcome`, `/price`, `/confirm`, `/repeat`)
4. Type `/welcome` in any chat to insert template instantly

**Telegram**
1. Use the @SaveAsBot or built-in saved messages
2. For automated FAQ replies: ManyChat ($15/mo) integration with Telegram

**Make/Zapier Automation (advanced)**
- Trigger: New booking confirmed in your CRM/Firestore
- Action: Auto-send confirmation template via WhatsApp/Telegram API
- Saves you 5-10 min per booking

### Personalization Rules:

1. Always insert the customer's name (or nickname) in the first line
2. Always reference something specific from prior conversation (their hotel, their preferred therapist, their last visit date)
3. Never send identical messages to two different customers — Telegram/WhatsApp users notice form letters
4. Edit `[BRACKETS]` BEFORE sending. Half-finished templates kill your credibility.

### Reply Speed = Conversion Rate

The data on Bangkok mobile massage bookings:
- Reply within 2 minutes: 70-80% conversion to booking
- Reply within 10 minutes: 40-50% conversion
- Reply within 1 hour: 10-15% conversion
- Reply after 4 hours: customer has already booked someone else

For a solo operator, speed matters more than perfect copy. Use these templates as your speed advantage.
