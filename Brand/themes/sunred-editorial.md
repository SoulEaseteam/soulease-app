# SunRed Editorial

The primary brand theme. Editorial monochrome — black, white, red. Built for the customer who chooses Bottega over Coach and Park Hyatt over a wellness resort.

## Color Palette

- **Black** `#0A0A0A` — Primary surface, page background. Dominates 75-80% of any composition.
- **Black Soft** `#161616` — Cards, modal panels, secondary surfaces.
- **Black Panel** `#1C1C1C` — Elevated panels, hover states.
- **White** `#FFFFFF` — Primary text, hairlines.
- **White Off** `#F6F4F0` — Paper-tone surfaces (PDF, print, voucher reverse).
- **Red** `#E50914` — The surgical accent. One per composition.
- **Red Deep** `#B30710` — Hover state, gradient base.
- **Red Bright** `#FF1E2C` — Highlight, gradient peak.

## Typography

- **Display Headers**: Gloock — heavy editorial serif. Use for hero typography (44-84pt).
- **Editorial Subheaders**: Italiana — refined high-fashion serif. Use for wordmark moments.
- **Reading Text**: IBM Plex Serif — body copy in long-form (vouchers, blog, brochures).
- **UI / Body**: Inter / Work Sans — interfaces, forms, app text.
- **Reference / Clinical**: IBM Plex Mono — voucher codes, dates, micro-labels (use 6-10pt with 0.15-0.2em letter-spacing).

## The Hierarchy Rules

- One headline per view. One red element per composition.
- Whitespace is 60-70% of any layout. Treat it as typography.
- All-caps reserved for clinical mono labels — never editorial serif.
- Red period `.` after key wordmarks (the SunRed signature gesture).

## Best Used For

The default theme for SunRed's app, gift voucher, concierge cards, brand-driven marketing, premium positioning campaigns, anything tied to the core SunRed identity.
