## 🚨 ความจริงก่อนเริ่ม

**ที่หลายคนไม่บอก:**

   - ทุกคนใช้ VPN/roaming · ไม่ติด Great Firewall

3. **ทางลัดที่ practical กว่ามาก** — Personal WeChat + QR code · ใช้ได้ภายใน 1 ชม.

## 🟢 PATH 1: Personal WeChat + QR — ⭐ แนะนำสุด

### ทำไมดี
- ฟรี · เร็ว · scale ได้พอสำหรับ SunRed
- ไม่มี verification process
- ส่งข้อความ broadcast ได้ (max 200 contacts/ส่ง)
- QR code วางบน taxi cards · website footer · concierge intro

### ขั้นตอน (1 ชม.)

1. **สร้าง WeChat account แยกสำหรับ SunRed:**
   - Download WeChat app
   - Register with **Thai phone number**
   - Username: `SunRedBangkok` (หรือ `SunRedBKK`)
   - Avatar: brand logo
   - Bio: `Premium outcall massage in Bangkok · 24/7 · sunred.vip`

2. **เปิด Discoverable settings:**
   - Settings → Privacy → Find me by Phone Number ✅
   - Settings → Privacy → My QR code → save as image

3. **ทำ QR poster:**
   - ใช้ QR code ที่ save มา
   - เพิ่มข้อความ: `加微信 / Add WeChat → SunRedBangkok`
   - Print หรือใส่ใน Telegram channel description

4. **Broadcast lists:**
   - WeChat → Me → Settings → Functions → Broadcast Assistant (群发助手)
   - สร้าง list ใหม่ · ใส่ contacts (max 200)
   - ส่ง broadcast message · ใช้ template จาก `seed-content-by-channel.md` §1

### ขีดจำกัด
- Broadcast = 200 contacts/ครั้ง (ส่งหลายรอบได้)
- 5,000 friends max ต่อ account
- ถ้าเกิน → สร้าง account ที่ 2

### คอนเซ็ปต์การใช้
```
ลูกค้าจีนมาเที่ยว
   ↓ taxi driver ส่งนามบัตร
   ↓ ดู QR · scan
   ↓ Add SunRedBangkok ใน WeChat
   ↓ พิมพ์ "你好" / 询价
   ↓ คอนเซียร์จะแชทตอบเป็นรายบุคคล
```

## 🟡 PATH 2: WeChat Group — ทำคู่ Path 1

## 🔴 PATH 3: Official Account (OA) — ทำเมื่อ scale พิสูจน์แล้ว

### ทำไมยุ่ง
- Verification ใช้เอกสารธุรกิจ TH แปล 中文
- Service Account (服务号) คือที่ใช่ · มี chat + broadcast
- Subscription Account (订阅号) ง่ายกว่า · broadcast รายวัน · feature น้อย
- **WeChat moderation อาจปฏิเสธ "massage" industry** — ความเสี่ยงสูง

### Cost
- ฿3,500/ปี verification
- ค่าจ้าง agent ในไทย/จีน 3,000-10,000 บาท one-time
- ค่าแปลเอกสาร 1,000-2,000 บาท
- Total: ~฿7,500-15,000 ตอน setup · ฿3,500/ปีต่อ

### เอกสารต้องมี
- Thai company registration (DBD certificate)
- Thai business license
- Personal ID/Passport (View)
- Domain proof (sunred.vip)
- Phone (TH หรือ CN)
- Email
- ทั้งหมดแปลเป็น 中文 + รับรอง

### หา agent ใน Bangkok
- Search Google: "WeChat OA agent Bangkok" / "微信公众号 注册 泰国"
- Facebook กลุ่ม "Chinese in Thailand business"
- หรือผ่าน Chinese embassy/consulate referral

### ความเสี่ยง
- ปฏิเสธเพราะ massage industry → เสียค่า verification
- ต้อง maintain content schedule · ไม่งั้น account inactive
- Compliance review ทุกครั้ง post content เกี่ยวกับ adult-adjacent

**→ ทำเมื่อ:** SunRed มี Chinese clientele 100+ ต่อเดือนแน่นอนแล้ว

## 🛠️ Practical tips จากประสบการณ์ industry

1. **WeChat Pay = แยกขั้นตอน** — ไม่ใช่ส่วน OA · ต้องสมัครเป็น merchant แยก
2. **Group banner image** — ใช้ภาพ brand · ดึงดูดมากกว่า text
3. **เวลา post ดีสุดสำหรับ Chinese tourist:** 11:00-13:00 + 19:00-22:00 (BKK time)
4. **Avoid posting:** Friday-Sunday morning (people travel · ไม่อ่าน)
5. **QR code recycling:** WeChat QR code refresh ทุก 7 วันโดย default · ใช้ permanent QR ของ contact info แทน group/OA QR

## 📱 ปัญหา 1 device 1 WeChat — ทางออก

WeChat บังคับ 1 account ต่อ device · ใช้พร้อมกัน 2 accounts บนเครื่องเดียวไม่ได้

### ทางออก ranked

| # | ทาง | ต้นทุน | ใช้ง่าย | คงทน |
|---|---|---|---|---|
| **1** ⭐ | มือถือเครื่องที่ 2 (มือสอง Android) | ฿2-5K | ดี | ยาว |
| 2 | Android Dual App (ถ้า phone support) | ฿0 | ดี | ยาว |
| 3 | iPad + Phone combo | ใช้ของที่มี | กลาง | ปานกลาง |
| 4 | ใช้ account เดียวสำหรับทั้ง personal + work | ฿0 | ง่าย | ยาว แต่ไม่ professional |

### 🟢 ทาง 1: มือถือเครื่องที่ 2 — ⭐ แนะนำสุด

**ทำไมดี:**
- แยก work/life ชัด · เปิด-ปิดได้
- ตัว WeChat ทำงานเต็มที่ · notifications แยก
- ใช้กับ Telegram/WhatsApp/LINE work accounts ได้ด้วย
- ตอนพักผ่อน · ปิดเครื่องนี้ได้ (ใจสงบ)

**ซื้อยังไง:**
- มือสอง Samsung A20/A30/A50 ~฿2,500-4,000 (Bangkok shopping mall, Lazada มือสอง)
- หรือใหม่ Redmi A2/Note 12 ~฿4,000-6,000
- ไม่ต้อง SIM ก็ได้ ใช้ WiFi เปิด WeChat บ้านได้
- ถ้าจะ register WeChat ใหม่ ต้องมีเบอร์ — ซื้อ DTAC/AIS เบอร์เปล่า ฿39

**ข้อดีพิเศษ:**
- ใช้เครื่องนี้รับ booking notification จาก Telegram bot เก่าได้
- ปลอดภัย ถ้าเครื่องส่วนตัว lost/stolen งานไม่ leak

### 🟡 ทาง 2: Android Dual App (ฟรี · ถ้า phone support)

**เครื่องที่ support:**
- Xiaomi · Redmi: Settings → Apps → Dual Apps
- Samsung: Settings → Advanced features → Dual Messenger
- OPPO/Realme: Settings → App Management → Clone Apps
- Huawei: Settings → Apps → App Twin
- Google Pixel: ❌ ไม่ support
- **iPhone: ❌ ไม่ support natively** (jailbreak risky)

**วิธีเปิด (Samsung เช่น):**
1. Settings → Advanced features → Dual Messenger
2. หา WeChat → toggle ON
3. WeChat ตัวที่ 2 ปรากฏใน app drawer
4. Register WeChat ใหม่ด้วยเบอร์ที่ 2

**ข้อจำกัด:**
- WeChat อาจ detect dual app + lock ในบางกรณี
- บางครั้ง update WeChat แล้ว dual ใช้งานผิดปกติ
- ไม่ทุก phone model ทำได้

### 🟠 ทาง 3: iPad + Phone

ถ้า View มี iPad อยู่แล้ว:
- Personal WeChat บน iPhone
- Work WeChat บน iPad (register แยก · เบอร์ที่ 2)
- ใช้พร้อมกันได้ (WeChat treat iPad เป็น 1 device แยก)
- ข้อเสีย: iPad ไม่พกพาง่าย · battery sync ต้อง charge 2 ที่

### 🔴 ทาง 4: ใช้ account เดียวสำหรับทั้งหมด

**ทำได้:**
- ตั้ง bio: "SunRed Bangkok concierge"
- ใช้ WeChat Tags แยก contacts: `personal` · `sunred-customer`
- Moments visibility: เลือกใครเห็น post ไหน
- เพื่อนสนิทไม่เห็น SunRed content · ลูกค้าไม่เห็น personal

**ข้อเสีย:**
- ไม่ professional (ลูกค้าเห็น avatar ส่วนตัว)
- ไม่มี boundary work-life
- Privacy risk (ลูกค้าอาจ search หา personal info)
- ถ้าลูกค้า unhappy → กระทบ social network ส่วนตัว

**ใช้เมื่อ:** งบ ฿0 · ไม่อยากซื้อเครื่องใหม่ · ยังไม่จริงจัง
