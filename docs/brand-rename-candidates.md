## 2. ตัวเลือก 6 ชื่อ

### 🥇 ORIA — อ่าน "โอ-เรีย"

| | |
|---|---|
| **ที่มา** | คำประดิษฐ์ รากละติน *ora* (ริมฝั่ง · ชายขอบ) |
| **ชื่อจีน** | **悦栖** Yuè Qī — "เพลิน + พักพิง" |
| **โดเมนที่ควรลอง** | oria.com · oriabangkok.com · oria.co · ขั้นต่ำ oriaspa.com |
| **Telegram** | @Oria_BKK · concierge @OriaConcierge |

**ทำไมถึงเชียร์อันนี้ที่สุด:**
- 4 ตัวอักษร สระเปิดหมด — ไม่มีทางสะกดผิด ไม่ว่าชาติไหนพูด
- อ่านเหมือนเชนโรงแรม ไม่เหมือนร้านนวด → นี่คือข้อที่ผ่านตา Google/Meta
- 悦 คือตัวอักษรที่แบรนด์โรงแรมหรูจีนใช้กันหมด (凯悦 Hyatt · 悦榕庄 Banyan Tree) ลูกค้าจีนจะอ่านแล้วรู้สึก "แพง" ทันที โดยไม่ต้องอธิบาย
- ไม่มีความหมายค้างในภาษาไหนเลย → ไม่มีอะไรให้ตีความผิด

**จุดอ่อน:** ชื่อสั้นแบบนี้ .com ว่างยาก เตรียมงบซื้อต่อ หรือยอมใช้ oriabangkok.com

### 🥈 THARA — อ่าน "ทา-รา"

| | |
|---|---|
| **ที่มา** | ธารา (ไทย/สันสกฤต) = สายน้ำ |
| **ชื่อจีน** | **汀屿** Tīng Yǔ — "หาดตื้น + เกาะ" |
| **โดเมน** | thara.com · tharabkk.com · thara.co |
| **Telegram** | @Thara_BKK |

- น้ำ = น้ำมัน = การไหล ตรงกับตัวบริการพอดี ไม่ต้องยัดคำอธิบาย
- **จุดอ่อนจริง:** ฝรั่งจะพิมพ์ "Tara" กันครึ่งหนึ่ง แล้ว Tara มีแบรนด์เต็มไปหมด → traffic รั่ว ถ้าเลือกอันนี้ต้องซื้อ tarabkk.com ดักไว้ด้วย

| | |

### SEREIN — อ่าน "เซอ-เรน"

- ฝรั่งเศส แปลว่า *ฝนละอองที่ตกลงมาจากฟ้าใสตอนหัวค่ำ* — สวยมาก ตรง quiet luxury
- ชื่อจีน **静屿** Jìng Yǔ (เกาะเงียบ)
- **จุดอ่อนที่ทำให้ไม่เชียร์:** คนได้ยินแล้วจะพิมพ์ "serene" ทุกคน แล้ว serene + spa มีแบรนด์ชนเป็นร้อย → เสีย traffic ทิ้งฟรีทุกวัน

### SUVANA — อ่าน "สุ-วา-นา"

- จากสันสกฤต *suvarna* (ทอง) และเสียงพ้อง สุวรรณภูมิ → ผูกกับกรุงเทพโดยไม่ต้องพูดคำว่ากรุงเทพ
- ชื่อจีน **澜庭** Lán Tíng (ระลอกคลื่น + ลาน)
- **จุดอ่อน:** สะกดได้หลายแบบ Suwana / Suvanna / Suvarna → รั่วเหมือน THARA

### LUNARA — อ่าน "ลู-นา-รา"

- ชื่อจีน **月栖** Yuè Qī (พระจันทร์ + พักพิง)

## 4. ⚠️ ราคาที่ต้องจ่าย — อ่านก่อนกดเปลี่ยน

Rename ทั้งแบรนด์ **ไม่ใช่แค่เปลี่ยนคำใน code** ของที่จะหายไปจริง:

1. **อันดับ Google ที่มีอยู่** — จาก Search Console: คำว่า "sunred massage" ตอนนี้ได้
   127 clicks / 160 impressions / อันดับเฉลี่ย **1.2** ใน 90 วัน และ clicks โต +105%
   ชื่อใหม่ = เริ่มนับหนึ่งใหม่หมด อันดับ 1.2 นี้ซื้อคืนไม่ได้
2. **@SunRed_BKK ~443 subs + booster 4 คน** — ย้ายช่องได้ แต่คนหายระหว่างทางแน่
3. **ป้าย/นามบัตรแท็กซี่ที่แจกไปแล้ว** — ตายทันทีวันที่เปลี่ยน
4. **Google Business Profile 3+ รายการ** ที่ยังไม่รู้ที่มา จะยิ่งงงหนักขึ้น
5. **งานในโค้ด** — domain, i18n 6 ภาษา, sitemap, blog 5 บทความ, bot 2 ตัว,
   Firebase project id (`soulease-spa` เปลี่ยนไม่ได้ ต้องยกโปรเจกต์ใหม่)

**ทางที่ถูกกว่าและได้ผลเหมือนกัน — เปิดเป็นแบรนด์ที่สอง ไม่ต้องฆ่า SunRed:**

ให้ชื่อใหม่ (เช่น ORIA) เปิดเป็น **แบรนด์คู่ขนาน** โดเมนใหม่ ช่อง Telegram ใหม่
หน้าเว็บใหม่ ทีมงานชุดเดียวกัน ระบบหลังบ้านตัวเดียวกัน แล้วปล่อยให้ SunRed
วิ่งเก็บ traffic เดิมต่อไปเงียบๆ ไม่ลิงก์หากันเลย (นี่คือความหมายจริงของ
"ไม่โยงถึง" — ไม่ใช่แค่ชื่อไม่เหมือน แต่คือ **สืบกลับไม่ได้**: คนละโดเมน
คนละ Telegram คนละ analytics คนละเบอร์ติดต่อ ไม่มีลิงก์ระหว่างสองเว็บ)

ได้ทั้งชื่อใหม่ที่ดูสะอาด ทั้งอันดับเก่าที่ยังทำเงินอยู่ · ถ้าแบรนด์ใหม่ติด
