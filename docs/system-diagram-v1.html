📋 BookingPage — Logic
  • รับ therapistId + serviceId จาก navigation state
  • ดึง therapist data จาก Firestore
  • เลือกวันที่ (DatePicker) + เวลา
  • ตรวจสอบ Slot ว่าง (check existing bookings)
  • คำนวณ Grab Fare: BASE 25฿ + 7฿/km + 2฿/min (× 2 ไปกลับ)
  • กรอก Address, Phone, Note
  • สร้าง Google Maps URL อัตโนมัติ
  • runTransaction: เพิ่ม todayBookings + totalBookings
  • ส่ง LINE Notify หา Staff
  • ส่ง Notification เข้า Firestore
💰 ค่าเดินทาง (Taxi Fare)
  • ดึง therapist.currentLocation จาก Firestore
  • ใช้ Google Directions API คำนวณระยะทาง
  • Fallback: Haversine formula ถ้าไม่มี API key
  • สูตร: (25 + km×7 + min×2) × 2
  • แสดงค่าเดินทางให้ลูกค้าเห็นก่อนยืนยัน
  • บันทึก taxiFee ลง booking document
